# Canal no YouTube — Direitos do Trabalhador e MEI (sem aparecer)

Pacote de conteúdo pronto para um canal **sem rosto** ("faceless") sobre direitos trabalhistas, folha de pagamento e MEI.

| Arquivo | O que é |
|---|---|
| [`01-estrategia-e-producao.md`](01-estrategia-e-producao.md) | Posicionamento, nomes sugeridos, formato sem rosto, ferramentas, passo a passo de produção e regras do YouTube |
| [`02-calendario-30-videos.md`](02-calendario-30-videos.md) | Os 30 primeiros vídeos longos + Shorts, em ordem de publicação |
| [`roteiros/`](roteiros/) | Roteiros completos dos vídeos longos (narração + o que mostrar na tela + título, descrição, tags e thumbnail) |
| [`shorts/`](shorts/) | Roteiros de Shorts (até 60 s) |

## Antes de publicar qualquer vídeo

1. **Confira os valores do ano** (salário mínimo, tabelas de INSS e IRRF, teto do seguro-desemprego, limite do MEI). Os roteiros evitam valores que mudam todo ano; onde aparecem, estão marcados com ⚠️.
2. Leia o roteiro em voz alta uma vez e ajuste para o seu jeito de falar.
3. Mantenha o aviso no fim do vídeo e na descrição: *"Conteúdo informativo. Cada caso tem particularidades; para o seu caso, procure um contador ou advogado."*
